# QR Code Camera Scanner - Admin Guide

## Overview
The QR Code Verification page now includes a real-time camera scanner that allows admins to verify bookings by simply pointing their camera at a QR code instead of manually pasting it.

## Features

### ✨ Two Input Modes
1. **📝 Manual Mode** (Default)
   - Paste QR code data from clipboard
   - Useful for scanned images or exported QR codes
   - No camera permission required

2. **📷 Camera Mode** (New)
   - Point camera at QR code
   - Real-time detection and automatic verification
   - Visual scanner frame overlay
   - Auto-closes camera after successful scan

## How to Use

### Step 1: Navigate to Admin Dashboard
- Log in as an Admin user
- Go to Admin Dashboard
- Click the "🔍 QR Verification" tab

### Step 2: Choose Input Method
- **To Scan**: Click "📷 Camera" button
- **To Paste**: Click "📝 Manual" button (default)

### Step 3: Using Camera Mode (Recommended)
1. Click "📷 Camera" button
2. **Allow Camera Permission** when prompted
   - Browser will ask for camera access
   - Click "Allow" to grant permission
3. Point your device's camera at the QR code
   - The QR code should be within the blue scanner frame
   - Keep the code stable and well-lit
4. **Automatic Verification**
   - When detected, the QR code is automatically scanned and verified
   - Camera closes automatically
   - Booking details appear below
5. Review the booking information
   - Verify booking details match the physical event/resource
   - Booking shows "VERIFIED" status with timestamp

### Step 4: Using Manual Mode
1. Click "📝 Manual" button
2. Copy QR code data (or take screenshot and extract data)
3. Paste into the textarea
4. Click "✓ Verify QR Code" button
5. Booking details will appear if verification succeeds

## Verification History

### Viewing History
- Scroll down to "Verification History" section
- Shows last 10 verified bookings
- Includes: Booking ID, Resource, User ID, and Verification Time

### Clearing History
- Click "🗑️ Clear History" button
- Requires confirmation
- Useful for starting fresh at the beginning of each day

## Troubleshooting

### Camera Permission Denied
**Problem**: Camera mode shows "Unable to access camera"

**Solution**:
1. Check browser settings for camera permissions
2. Ensure camera is not in use by another application
3. Try reloading the page
4. Use Manual mode as a fallback
5. Try a different browser if available

### QR Code Not Detecting
**Problem**: Camera is on but QR code not scanning

**Solutions**:
- Ensure QR code is within the blue scanner frame
- Check lighting - QR codes need adequate light
- Keep camera steady and close to the QR code
- Ensure QR code is not damaged or obscured
- Try moving the code closer or further from camera
- Switch back to Manual mode to paste data

### "Invalid QR Code Format" Error
**Problem**: Scanned or pasted QR code is invalid

**Solution**:
- Verify the QR code is a booking QR code (generated by system)
- Check that the QR code hasn't been corrupted
- Try scanning from a different angle
- Contact administrator if QR code generation failed

### Booking Not Found Error
**Problem**: QR code verified but booking not found

**Solution**:
- Booking may have been deleted
- Try rescanning or repasting the QR code
- Check booking ID in the QR code data
- Contact administrator to investigate

## Best Practices

### ✅ For Efficient Scanning
1. **Good Lighting**: Ensure the room is well-lit
2. **Steady Hand**: Hold camera stable while scanning
3. **Proper Distance**: Keep QR code 10-20cm from camera
4. **Frame Alignment**: Center QR code in the scanner frame
5. **Batch Processing**: Verify multiple bookings consecutively

### ✅ For Accurate Verification
1. Check booking details match the physical event
2. Verify resource matches what's being used
3. Confirm user is present (if applicable)
4. Note any discrepancies in comments
5. Review verification history at end of session

### ✅ Mobile Device Tips
1. Use back camera for better QR code capture
2. Hold device horizontal (landscape) for larger frame
3. Enable brightness/auto-focus if available
4. Clean camera lens before use
5. Disable screen lock timeout to avoid interruption

## Technical Details

### QR Code Format
Booking QR codes follow this format:
```
BOOKING_VERIFY|bookingId|resourceId|userId
```

Example:
```
BOOKING_VERIFY|507f1f77bcf86cd799439011|LAB_101|user@university.edu
```

### Verification Process
1. Camera captures video frame
2. jsQR library decodes QR code from frame
3. QR data sent to backend via POST /bookings/verify-qr
4. Backend validates QR format and booking exists
5. Backend checks booking details match QR data
6. Backend marks booking as verified (if valid)
7. Frontend displays booking details with verification timestamp

- ✅ Mobile Browsers: Full support

## FAQ

**Q: Can I use any QR scanner app instead?**
A: Yes! You can use any QR scanner to get the QR data, then paste it in Manual mode.

**Q: What if the camera is blurry?**
A: Try cleaning the camera lens or adjusting distance. Most phones have auto-focus that should work.

**Q: Can I verify multiple bookings quickly?**
A: Yes, after each verification, simply scan the next QR code. The camera reopens automatically.

**Q: Is my camera data stored anywhere?**
A: No. Camera stream is processed locally in your browser only. No data is uploaded or stored.

**Q: What if I deny camera permission?**
A: You can still use Manual mode to paste QR code data. You can re-enable camera permission in browser settings.
