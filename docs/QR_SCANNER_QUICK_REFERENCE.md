# QR Camera Scanner - Quick Reference

## 🚀 Quick Start
1. Go to Admin Dashboard → QR Verification
2. Click **📷 Camera** button
3. Allow camera permission when prompted
4. Point camera at QR code
5. ✓ Booking verified automatically!

## 📋 Mode Toggle
| Mode | Button | Use Case |
|------|--------|----------|
| **Manual** | 📝 | Paste QR data from clipboard |
| **Camera** | 📷 | Real-time QR scanning |

## 🎯 Camera Tips
- ✅ Good lighting (not too bright, not too dark)
- ✅ Steady hand (brace against something)
- ✅ 10-20cm distance from QR code
- ✅ Center QR code in blue frame
- ❌ Avoid: Shadows, glare, blur

## 📊 Verification Status
- 🔵 Blue Frame: Scanner ready
- 🟢 Green Badge: Successfully verified
- 🟡 Yellow Badge: Pending verification
- 🔴 Red Error: Verification failed

## 🔧 Keyboard Shortcuts
- `Escape`: Close camera
- `Tab`: Switch to manual mode
- `Enter`: (in manual mode) Verify QR code

## 💾 History
- Last 10 verifications saved
- Shows: Booking ID, Resource, Time
- Clear with: 🗑️ Clear History button

## ⚠️ Troubleshooting
| Issue | Fix |
|-------|-----|
| Camera won't open | Check permissions, try different browser |
| QR won't scan | Better lighting, steady hand, center code |
| "Booking not found" | Code may be invalid, try manual mode |
| Permission denied | Allow in browser settings, then refresh |

## 🔒 Security Notes
- No data stored locally
- Camera stream = local only
- Verification logged on backend
- History stored in browser cache

## 🌐 Browser Support
- Chrome/Edge: ✅ Full support
- Firefox: ✅ Full support  
- Safari: ✅ Full support
- Mobile: ✅ Full support

## 📱 Mobile Tips
1. Use back camera (better quality)
2. Horizontal orientation (bigger frame)
3. Enable auto-focus if available
4. Keep brightness on
5. Close other apps using camera
